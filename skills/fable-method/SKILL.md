# Fable Method：七步決策流程

當遇到複雜、高風險或重要決策時，採用以下七步結構化流程：

## 七步決策流程

1. **分類** — 明確任務的性質、風險等級、影響範圍
2. **定義完成標準** — 清楚列出成功的衡量指標
3. **收集證據** — 蒐集相關資訊、測試案例、已知約束
4. **做決策** — 基於證據做出單一、明確的決策
5. **執行** — 按計畫實行，記錄過程中的發現
6. **驗證** — 對抗式檢查結果（找出虛假完成、削弱測試等）
7. **報告** — 記錄決策理由、執行過程、驗證結果

## 何時使用

✅ **使用此流程**：
- 架構性重構或大規模修改
- 需要在多個方案中選擇
- 修改影響多個系統/模塊
- 涉及安全或資料完整性的決策

❌ **無需此流程**：
- 小範圍、低風險的單一檔案修改
- 明確的 bug 修復（已知原因和解決方案）
